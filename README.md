# Caesar Cipher 🔐

A simple **Caesar Cipher** implementation in Python.
This program allows you to **encrypt** and **decrypt** text using a shift key.

## Features

* Encrypt messages with a custom shift value.
* Decrypt messages back to plain text.
* Supports both uppercase and lowercase letters.
* Keeps spaces, numbers, and special characters unchanged.
* User-friendly command-line interface with input validation.

## Usage

1. Run the script:

   ```bash
   python caesar_cipher.py
   ```
2. Choose a mode:

   * `e` → Encrypt
   * `d` → Decrypt
   * `q` → Quit
3. Enter your message.
4. Enter a shift value (number).
5. View the result instantly.

## Example

```text
Enter 'e' to encrypt, 'd' to decrypt, or 'q' to quit: e
Enter your message: Hello World
Enter shift value (number): 3

Result: Khoor Zruog
```

## Why This Project?

The Caesar Cipher is one of the earliest and simplest encryption techniques.
This project demonstrates **basic cryptography concepts**, **string manipulation**, and **Python control flow** — great for beginners.
